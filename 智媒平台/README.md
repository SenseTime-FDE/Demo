# 人民日报社 · 智媒平台 2.0 高保真交互原型

本原型依据《智媒平台需求说明书》搭建，覆盖 PC 端、移动端、多用户登录、角色分权限、AI 数字员工、采编协同、数据基座和平台治理。

纯静态 HTML / CSS / JavaScript，无外部依赖，可离线打开。所有人物、稿件标题、业务数字和效果数据均为目标态示意，不代表人民日报社真实信息。

## 打开方式

最简单：双击 `login.html`。

如浏览器限制本地文件，可在本目录启动任意静态文件服务，然后访问 `login.html`。例如：

```bash
python3 -m http.server 3471
```

访问：`http://127.0.0.1:3471/login.html`

## 视觉与体验

- 默认“透红色”暖白底，人民日报红仅用于标识、重点和预警。
- 支持轻量淡色、科技蓝两套辅助皮肤，全站即时切换并记忆。
- PC 端承载复杂生产流程和全量分析；移动端承担轻量指挥、看板、审批与即时提醒。
- 全站带演示水印、AIGC 标识、分级查看提示与人工终审红线。

## AI 数字员工 Demo

每个角色拥有不同数字员工和业务剧本。对话会展示：

1. 用户任务；
2. AI 思考；
3. 调用的智能体、知识库或流程节点；
4. 可编辑结果卡；
5. AIGC 标识与人工确认点。

重点剧本包括选题推荐、录音转写成稿、英文转译、三审三校、舆情研判、采前会准备、传播复盘、对话问数和平台运行日报。
