# 展位选择与主办方定价业务参考

## 资料用途

本资料用于校准“主办方招商销售内部 Agent Demo”的业务逻辑。Demo 中的展位价值分析、动态报价、销售推荐和 Agent 话术应围绕这些实际业务原则展开。

## 一、展商如何判断展位价值

### 1. 展位位置

展商选择展位前，通常会依据主办方提供的现场展位平面图判断位置。平面图一般会标注：

- 展馆入口
- 展馆出口
- 主通道
- 侧通道
- 功能区
- 会议区
- 咨询台
- VIP 休息室
- 观众休息区
- 洗手间
- 电梯
- 礼品发放或抽奖区

观众流量通常集中在：

- 展馆出入口处
- 出入口两侧
- 展厅主通道
- 主通道十字路口
- 功能区附近，例如休息区、VIP 室、洗手间、电梯、咨询台、会议区、礼品发放区、抽奖区

这些位置的共同价值是：

- 人流量大
- 流通性强
- 容易形成观众集中
- 更容易吸引过往观众注意品牌
- 更容易邀请观众进入展位参观洽谈

### 2. 展位类型

展位一般分为标准展位和光地展位。

#### 标准展位

标准展位通常为 9㎡ 或 12㎡，由组委会指定的官方搭建商统一搭建。

标准展位又分为：

- 单开口标准展位
- 双开口标准展位

单开口标准展位：

- 夹在一排展位中间
- 观众只能从正前方过道进入
- 租金通常最低

双开口标准展位：

- 位于一排展位的第一个或最后一个
- 两面邻过道
- 观众可从前方通道和垂直通道进入
- 人流量较大
- 展示效果较好
- 租金通常高于单开口展位

#### 光地展位 / 特装展位

光地展位又称特装展位，通常 36㎡ 起申请。

特点：

- 由参展商自行搭建或委托展览公司设计搭建
- 组委会通常不参与搭建
- 可根据产品特点、技术特点、品牌形象、市场定位和现场活动安排进行定制装修
- 更适合提升品牌曝光、吸引买家和潜在合作伙伴

### 3. 借势选择

如果企业知名度不高，但预算相对充足，应尽量选择位置好、人流量大的展位。

如果预算较低，可以采用“借势”策略：

- 选择靠近知名品牌或头部企业的展位
- 借助头部品牌带来的人气和专业观众流量
- 同时需要销售人员帮助客户理解借势价值，并提升展台吸引和转化能力

### 4. 提前预定

好的展位具有稀缺性。展商确定参展并选定满意位置后，应尽快与主办方沟通、签订合同、支付定金并锁定展位。

业务含义：

- 优质展位会被快速预定
- 稍有迟疑可能被其他企业或竞争对手抢先锁定
- 主办方销售推荐时应强调优质展位的锁位时效和库存稀缺性

## 二、主办方展位定价因素

展位销售价格由展会主办方确定。主办方定价时主要考虑四类因素。

### 1. 成本因素

成本是定价的基础。

- 销价低于成本：亏本销售
- 销价等于成本：保本销售
- 销价高于成本：盈利销售

展览项目经营成本可通过财务预算提前测算，并在项目结束后通过财务决算验证。

展位单位成本可通过以下方式测算：

```text
展位单位成本 = 展览项目营业成本总额 ÷ 展位总数
```

“成本 + 利润”是主办方定价的基本方法。

### 2. 市场因素

影响展位售价的市场因素主要包括：

- 举办地经济发展与消费水平
- 同一城市、同一展馆的展会价格参照
- 同主题展会之间的竞争
- 展会影响力差异，例如国际性、全国性、区域性

一般而言：

- 国内展会展位价格普遍低于国外展会
- 国内中西部地区价格通常低于北上广
- 北上广项目运营成本更高，场馆租金通常明显高于其他城市
- 同主题展会之间可能用展位价格作为竞争手段

### 3. 规模因素

展会规模越大，主办方销售定价的自由度通常越大。

可参考规模口径：

- 2 万平方米以下：小型项目
- 5 万平方米以上：大型项目

规模越大，品牌影响力、招商能力和价格调节空间通常越强。

### 4. 价值因素

品牌展会的价值体现在客户忠诚度和客户认可度。

通常具备以下特征的展会更容易支撑较高价格：

- 参观效果好
- 展览规模大
- 服务品质高
- 专业观众质量高
- 客户复购率高
- 展会品牌影响力强

品牌展会的展位售价通常明显高于非品牌展会。

## 三、主办方销售价格制定方法

展位销售价格制定应体现：

### 1. 计划性

销售价格应在销售业务启动之前制定。

### 2. 综合性

制定价格时应综合考量：

- 成本
- 市场
- 规模
- 价值

其中，成本是基础性因素；市场和价值因素需要定价决策者判断；规模是项目实际经营状况。

新项目定价通常基于成本和市场预测。

### 3. 动态性

展位价格不应长期不变，应随着经济发展、项目成熟度、销售阶段和市场反馈调整。

一般趋势是由低向高，但也会因销售进度和市场竞争进行阶段性调整。

### 4. 灵活性

展位价格应在规范下灵活应变，可根据以下因素调整：

- 不同市场
- 不同客户
- 不同销售策略
- 不同销售阶段
- 不同区域库存情况
- 不同客户价值

展览项目通常会制定对外销售基准价格。基准价格通常可理解为对外销售最低限价或底价。之后主办方会根据客商情况制定营销政策。

## 四、对 Demo 的业务约束

### 应当体现

- 展位价值不仅由热力决定，还应包含入口、主通道、十字路口、功能区邻近程度。
- 展位类型应影响价格：单开口标准展位 < 双开口标准展位 < 光地/特装展位。
- 靠近头部品牌可形成借势价值，尤其适合知名度不足但希望获得专业流量的客户。
- 优质展位应体现锁位紧迫性。
- 主办方动态定价应体现成本、市场、规模、价值四类因素。
- 销售端应展示内部报价区间、底价、审批规则和对外话术。
- 对展商不应暴露底价、库存压力、算法系数和内部审批规则。

### 不应当体现

- 不应让用户手动选择“竞品密度高/库存紧张/头部品牌多”来生成结果。
- 不应让动态价格看起来是随意生成的单点价格。
- 不应把展位推荐做成展商自助选位工具。
- 不应把主办方内部定价逻辑完整暴露给展商。
