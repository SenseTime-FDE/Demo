指标这个数怎么用

在院当前在院看护多少人，盯覆盖率与缺口覆盖
出院今天出院多少，谁该转私域做复购随访复购

组织与激励：去中层、增班组长、有奔头

组织扁平化去「项目主管」层、经理直管班组长，层级由 4 级压到 3 级扁平
班组长补贴本质是增加班组长：每月多拿 500-1500 元班组长补贴多挣钱
晋升通道护工 → 骨干 → 班组长 → 区域合伙人；资深班组长可兼店长（单院自负盈亏）有通道
原主管去向原项目主管转项目经理助理，减层不减人心有安置

这笔账：S-Agent 的 token 费用从减「项目主管」层省下的人力成本出——减 1 名主管 ≈ 覆盖 5-7 名班组长补贴 + 全组 token（目标态测算）。少一层传达，效率反而更高。
