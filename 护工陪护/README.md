# 陪护 AI 平台 · 高保真交互原型

基于《医院陪护 · 私域运营 + 数据看板 + 组织愿景 v8.0》PPT（`ppt_build_peihu/`）构建的对客演示原型站。
纯静态 HTML/CSS/JS，**零外部依赖、完全离线可用**。

## 打开方式

- 直接双击任意 `.html` 文件即可（推荐从 `index.html` 进入）；
- 或起本地服务：`npx serve peihu_proto -l 3457` → http://localhost:3457

## 设计系统

- 调色板与 v8 deck 完全一致：暖珊瑚 `#E8804D` + 科技青 `#148A9C` + 深青墨 `#12333B`（见 `assets/style.css` 顶部 token）
- 微信对话场景引擎：`assets/chat.js`（`PeihuChat.mount`，语音气泡 + ASR 转写 + 企微应用卡片）
- 商汤 logo：`assets/st_logo.png`（彩色）/ `st_logo_white.png`（深底用）

## 口径声明

页面中全部数字为 **目标态示意**（取自 v8 deck 第 25/28/29/30/31 页），非真实经营数据。
