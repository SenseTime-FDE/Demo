管理者在六级下钻中的位置与 KPI

L1公司总览运营中心 · 营收达成率 / 在管床位数 / 净利率
L2战队战队长看名下 n 家医院 · KPI：医院经营健康度 · 赋能覆盖率 · 跨院复制数
L3项目 · 医院店长（项目经理）单院全景 · KPI：单院利润 · 护工满编率 · 客户 NPS
L4科室床位覆盖率 / 科室毛利 / 投诉差评率
L5班组人均产值 / 排班履约率 / 任务完成率
L6护工个人累计收入 / 累计服务 / 工单完成 / 引流转化

同一套指标一钻到底：店长从单院全景一路钻到某个护工当天干没干；战队长横向对比 n 家医院——赋能指导非管控，复制打法、育人才。配合 chatBI，任何层级任何口径一句话就问到。

组织扁平化：4 级压 3 级，店长自负盈亏

现在 · 4 级（层层传达 · 反射弧长）

减层后 · 3 级（AI 替管理层看数据、催任务、汇总）
项目经理 · 直管→ 班组长带教 10-30 人→ 护工
医院 = 最小经营单位店长（项目经理）单院自负盈亏第一责任人店长制
原项目主管转项目经理助理，管理层由战队长承接转岗
