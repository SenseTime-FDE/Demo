# 中海油 × 商汤 · AI 应用方案站（高保真交互原型）

面向**中海油信息科技**的 AI 落地方案 + 分角色可交互原型。基于两份素材构建：
- 《中海油走进商汤·分享材料.pptx》（韩启微 v4.0 主题演讲）
- 《赴商汤深圳湾总部 AI 展厅参观暨技术交流函》

设计参照 `peihu_proto` / `jundu_proto` 模式：**共享微信语音对话引擎（chat.js）+ 分角色 Agent 页 + 现场小程序 + 生产 BI + 原型导览（实时 iframe 预览）**。纯静态、零外部依赖、离线可用。**深海科技暗色主题**。

## 打开方式
```bash
npx serve 中海油AI方案 -l 5178   # → http://localhost:5178
```
或直接双击 `index.html`（file:// 下 iframe 预览优雅降级）。

## 资源

- `assets/style.css` — 深海科技暗色设计系统（页面外壳）
- `assets/wx.css` — 微信/企微对话组件（手机内浅色真实感）+ 角色页面板
- `assets/chat.js` — `HYChat` 语音 Agent 对话引擎（源自 peihu 的 PeihuChat：语音气泡→ASR 转写→企微应用卡片→场景切换）
- `assets/app.js` — 导航 / 滚动揭示 / 计数
- `assets/st_logo.png` — 商汤 logo（从分享 PPT 提取，白字版·适配深色导航）
