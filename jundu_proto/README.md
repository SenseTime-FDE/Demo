# 君度智链 · 双引擎平台 —— 高保真原型站

「咨询 + AI」双引擎方案（君度咨询 × 链一链智能 × 商汤）的网站化输出 + 分角色交互 Demo。
纯静态、零外部依赖，可离线演示。演示数据均为虚构（客户品牌「云台酒业 · 青云39」为虚构）。

## 本地预览

```bash
cd jundu_proto
python3 -m http.server 8642
# 打开 http://localhost:8642/index.html
```

## 结构

- `assets/style.css` — 全站设计系统（君度红 C42128 × 鎏金 A97E2F × AI 墨蓝 23406E），前半部分与 peihu_proto 同构（组件类名一致），后半为驾驶舱/小程序/蒸馏扩展组件
- `assets/chat.js` — 企微语音对话引擎（AgentChat，源自 peihu_proto 的 PeihuChat，仅改名）
- `assets/data.js` — 全站共享数据底稿 window.JD（人物/组织五级层级/指标/预警/蒸馏数据），三个角色页数据同源
- 配套 39 页 PPT 方案在 `../ppt_build_jundu/君度咨询_AI应用场景与路线图_v1.0.pptx`
