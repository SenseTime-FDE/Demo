# 报社 AI · 一线 Agent 与社会价值运营 —— 高保真交互原型

配套《商汤_报社AI_一线Agent与社会价值运营方案_v1.0》PPT（`ppt_build_baoshe/`）构建的对客演示原型站，面向人民日报、健康报、中国妇女报等国资报社（IT 部门与经营管理层）。
纯静态 HTML/CSS/JS，**零外部依赖、完全离线可用**。

## 打开方式

- 直接双击任意 `.html` 文件即可（推荐从 `index.html` 进入）；
- 或起本地服务：`npx serve baoshe_proto -l 3459` → http://localhost:3459

## 设计系统

- 调色板与 deck 同族：藏青 `#0C2545` 骨架 + 人民红 `#B43A3A` 主强调 + 鎏金 `#C2A14B` + 宣纸白 `#FAF8F3`（见 `assets/style.css` 顶部 token）
- 企微对话场景引擎：`assets/chat.js`（`BaoChat.mount`，语音气泡 + ASR 转写 + 企微应用卡片）
- 商汤 logo：`assets/st_logo.png`（浅底）/ `st_logo_white.png`（深底）
- 大模型口径：SenseAudio-S2 旗舰大模型（推理）× SenseAudio-V2 语音大模型（语音）· 日日新可私有化部署

## 口径声明

页面中全部数字为**目标态示意口径**，非真实经营数据；客户报社名仅作定制示例。
合规红线贯穿各页：AI 辅助不替代终审签发、不碰采编导向、SVI 指标不得变相摊派订报、敏感人群数据脱敏聚合、AI 语料授权边界清晰。
