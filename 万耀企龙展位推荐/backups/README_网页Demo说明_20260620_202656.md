# 万耀企龙展位智能推荐与动态定价说明

## 文件

主页面：`万耀企龙展位智能推荐动态定价Demo.html`

## 打开方式

直接双击 HTML 文件，使用 Chrome 或 Edge 浏览器打开即可。无需安装后端、数据库或构建工具。

## 页面定位

该页面已调整为“客户前台 + 运营后台”的单文件展示应用。

- 客户前台：展示客户需求录入、AI 推荐方案、场馆地图、展位详情和客户版报价单。
- 运营后台：集中展示价格策略中心、模型参数配置、运营数据看板、展位状态管理、客户线索管理和报价审核记录。

## 客户展示流程

1. 进入首页概览，查看系统能力与场馆指标。
2. 在“客户需求录入”区域填写客户信息，其中“企业规模”按人数区间选择。
3. 点击“生成 AI 推荐”，查看最优适配、高端升级、性价比三档推荐方案。
4. 在“场馆地图”中按等级、状态、面积、价格筛选展位，点击展位查看详情。
5. 在“智能报价单”区域确认客户可见报价内容。
6. 点击“打印 / 保存 PDF”，通过浏览器打印功能输出客户报价单。

## 后台管理范围

后台管理区面向内部运营团队使用，包含：

- 价格策略中心：查看基础价、价值系数、供需系数、客户权益系数、时间浮动系数与价格边界。
- 模型参数配置：调整推荐权重、最高溢价上限、最低折扣下限，并重新计算推荐和报价。
- 运营数据看板：查看展位空置率、推荐成交率、溢价收益、销售结构和热门/滞销展位。
- 展位状态管理：按等级汇总可订、锁定、已售状态。
- 客户线索管理：展示当前客户与样例线索的跟进状态。
- 报价审核记录：展示报价单、价格边界和展位锁定审核结果。

## 客户侧信息隔离

客户前台不展示以下内部信息：

- 价格系数、溢价系数、折扣系数。
- 报价计算公式和价格拆分明细。
- 运营数据看板。
- 模型参数配置。
- 内部价格策略中心。

客户版报价单仅保留展位报价、推荐理由、服务说明、报价有效期和联系信息。

## 数据说明

页面为前端静态展示应用，展位、报价、成交记录、看板指标和客户线索为样例数据，用于产品方案展示。实际商务报价和服务内容以正式合同为准。
