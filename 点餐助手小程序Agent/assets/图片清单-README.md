# 图片放置说明

把准备好的图片按下面的文件名放进对应目录即可，网站会自动加载。
**图片缺失也没关系**：首页大图会回退到品牌暖色块，菜品会回退到 emoji 图标，页面不会破。

**菜品图支持 WebP 优先**：网站会先找 `<id>.webp`，没有再找 `<id>.jpg`，都没有就显示品类渐变色块 + emoji。
首页大图用 `.jpg`。命名需严格一致。

---

## 1. 首页整屏轮播大图 → `assets/hero/`

横版大图，建议 1600×900 以上、文件不超过 ~400KB（注意压缩，否则首屏慢）。
左侧约 1/3 会被文字蒙版覆盖，主体食物请尽量放在画面中右侧。

| 文件名 | 建议内容 |
| --- | --- |
| hero-1.jpg | 招牌能量碗 / 沙拉大片 |
| hero-2.jpg | 鲜榨果汁 / 饮品 |
| hero-3.jpg | 摩登亚洲主食 |
| hero-4.jpg | 三明治 / 早午餐 |
| hero-5.jpg | 门店或食材氛围图 |

## 提示

- 改完图片后直接刷新网页即可看到，无需改代码。
- 若要改文件名规则或新增菜品，对应修改 `index.html` 中 `MENU` 数据与 `assets/dishes/<id>.jpg` 命名。
- 正式上线请确保 `assets/` 目录随 `index.html` 一起部署。
