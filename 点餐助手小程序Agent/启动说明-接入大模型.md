# 用大模型实现智能对话 · 启动说明

纯静态网页不能直接调大模型（API key 会暴露），所以用一个**零依赖的本地后端**（`server.js`）做代理。
前端已写好：检测到后端就自动切到「AI 模型版」，没有后端就用「规则版」，永不报错。

---

## 方案 A：本地免费模型（推荐 · 不需要 API key）

用 [Ollama](https://ollama.com) 在你自己电脑上跑开源模型，免费、离线。

1. 安装 Ollama：到 https://ollama.com 下载安装。
2. 拉一个中文友好的小模型（约 2GB）：
   ```bash
   ollama pull qwen2.5:3b
   ```
   （电脑配置好可换更强的：`qwen2.5:7b`、`llama3.1:8b` 等，再改 `OLLAMA_MODEL`）
3. 启动本项目（需 Node 18+）：
   ```bash
   node server.js
   ```
4. 浏览器打开 **http://localhost:5173** —— 助手右上角会自动显示「AI 模型版」，开始智能对话。

---

## 方案 B：云端 API（需要一个 API key）

适用于已有 OpenAI / 兼容服务（DeepSeek、通义、Moonshot 等多数都兼容此格式）。

```bash
LLM_MODE=openai \
OPENAI_URL=https://api.openai.com/v1/chat/completions \
OPENAI_KEY=你的key \
OPENAI_MODEL=gpt-4o-mini \
node server.js
```

换其它服务商：把 `OPENAI_URL` / `OPENAI_MODEL` 改成对应的兼容地址与模型名即可。

---

## 工作原理（为什么安全、不会乱推荐）

- **模型只做语言层**：把用户的话理解成结构化意图 `{餐段, 口味, 忌口, 预算}`，并决定是「追问」还是「可以推荐」。
- **确定性引擎做决策**：真正"推荐哪几道、能不能吃、多少钱、多少热量"，仍由前端的 `chatRecommend()` 按菜单数据库**硬过滤 + 排序**。模型不碰这部分 → 不会把荤菜推给纯素用户、不会编造价格。
- **自动降级**：模型超时/报错/未运行后端时，前端自动回退到规则版，演示不中断。

涉及文件：`server.js`（后端代理）、`index.html` 内 `LLM_CONFIG` / `LLM_SYSTEM` / `callModel()`（前端接入点）。

---

## 常见问题

- **直接双击 index.html 打开**：没有后端，助手用规则版（完全可用），这是预期行为。
- **想换模型**：改 `OLLAMA_MODEL` 或 `OPENAI_MODEL`。
- **端口被占用**：`PORT=8080 node server.js`。
- **部署上线**：把 `server.js` 部署到你的服务器（密钥放服务器环境变量），前端 `LLM_CONFIG.endpoint` 指向它即可。
