# LBS 史伟莎 × 商汤 · AI 现场服务高保真原型站 — 构建规范（SPEC）

对客演示原型站，展示 AI 在史伟莎（虫害防制/卫生服务龙头）的三大落地场景：**一线技师 Agent**、**AI 智能客服**、**AI 工单智能调度**。参照 `../peihu_proto/` 的架构与质感（微信语音 Agent 手机原型 + 深色管理台 + LIVE 缩略导览）。

## 0. 硬性约束
- 纯静态 HTML/CSS/JS，**零外部依赖、零外链**（无 CDN/字体/图标库），完全离线可用。图标一律用 emoji 或纯 CSS。
- 每页公共资源：`assets/style.css`（设计系统，类名与 peihu_proto 完全一致）、`assets/chat.js`（`window.LBSChat`，API 同 PeihuChat）、`assets/st_logo.png`（彩色，浅底用）/`assets/st_logo_white.png`（深底用）。
- **配色（2026-07-21 起对齐 LBS 官网 lbsgroup.com.hk；token 名沿用旧名不改、只换值）**：LBS 品牌蓝 `#1A7AD2`（主色=官网导航蓝，占 --teal 槽）+ 深蓝 `#1359A8` + 藏蓝 `#0E2A4E`（--ink；深色页渐变 #081D3D/#0A2547/#061831）；卫生红 `#CE4A2D`（--warm 槽：急单/关怀，衍生自 LBS Hygiene 红标）；官网绿 `#00A100`（--ok：成功/完成语义，来自官网绿缎带）；页面底 `#F7FAFD`、浅蓝 tint `#E9F4FC`；深色页亮字用 #6CB8F5/#8CC8F7 蓝系。新增样式一律取用这套值。

- 所有经营数字（工单量/派单率/SLA 等）为虚构，页面显著处标注「**目标态示意**」；页脚统一：`商汤科技 · 大模型生态渠道部 — AI 技术底座 · 高保真交互原型（页面数据均为目标态示意，非真实经营数据）`。

## 4. LBSChat 引擎 API（assets/chat.js，勿改引擎）
```js
LBSChat.mount(document.getElementById('phone-slot'), {
  contact: { name:'随行助理', corp:'@史伟莎', sub:'商汤 S-Agent · AI 技术底座' },
  user:    { name:'陈国栋', avatar:'陈' },
  agent:   { avatar:'莎' },
  scenarios:[ { id:'s1', title:'今日工单', chip:'今天有什么安排', intro:'系统提示…', steps:[…] } ]
})
```
step：`{from:'agent'|'user', voice:'转写文字', dur:8}` 语音（自动出 ASR 转写条）｜`{text:'…'}` 文本（支持 `<b>`）｜`{html:'<div class="c-card">…'}` 企微卡片｜`{sys:'…'}` 系统灰字｜`delay` 可选。
卡片组件类（style.css 已备）：`.c-card .c-head .c-ic(.warm) .tag(.teal/.warm/.ok/.gold/.warn) .c-kv .c-big .c-steps .c-check(.s.done/.todo/.warn) .c-btns .c-btn(.primary/.ghost) .c-foot .c-bars`。卡片宽 262px，文案要短。
角色页骨架（照抄 peihu_proto/agent_hugong.html 的版式）：`.page > .page-head + .split`，左 `.phone-wrap > #phone-slot + .phone-caption`，右若干 `.panel`（h3 + .cap-grid/.flow/.mini-table/.note）。
